# POLIS — 정치 구조 발생 시뮬레이터

> 시민의 심리에서 정당이 생기고, 정당이 제도를 만들고, 제도가 다시 시민을 바꾼다.

POLIS는 **단일 HTML 파일**로 돌아가는 정치 시뮬레이터입니다. 정당·정부·헌법을 미리 정해두지 않습니다. 3,000명의 시민이 저마다의 심리·계급·지역을 갖고 살아가며, 그들의 선호가 모여 정당이 **발생**하고, 정당들의 경쟁이 선거제와 헌법을 **바꿔 나갑니다**. 한 틱은 1개월이고, 400년을 돌리면 체제 전환·개헌·정당 체계 재편이 스스로 일어납니다.

- **실행**: `polis.html`을 브라우저에서 열면 끝. 서버·설치·네트워크 불필요
- **크기**: 약 1.5MB/약 24,000줄
- **대상 환경**: 데스크톱 브라우저, iOS Safari (모바일 레이아웃 지원)

## 1. 빠른 시작

1. `polis.html`을 연다
2. 시작 화면에서 **지역 구조**(기본 12개 / 생성 6~50개)와 **시스템 범위**를 고른다
   - **기본** — 핵심 시스템만 (정당·선거·정부·계파·쟁점·경선·교차투표)
   - **전부 켜기** — 로비·지방정치·정치자금·언론편향·사법정치·선거인단·문서 보관까지 전부
   - **최소** — 정당·선거·정부만 (순수 선거제 실험용)
3. **시작**을 누르면 1개월 단위로 시간이 흐른다. 상단 속도 버튼(1× / 4× / 최대)으로 조절
4. 선거가 치러지면 결과 팝업이 뜨고 **시간이 자동으로 멈춘다**. "계속 진행"으로 재개

> 팝업을 끄고 빠르게 돌리려면 설정(⚙)에서 하원·상원·대선 팝업을 개별로 끌 수 있다.

## 2. 핵심 모델

### 2.1 시민

시민 3,000명이 각자 다음을 가진다.

| 범주 | 변수 |
|---|---|
| **심리 6축** | 개방성/공포/동조성/부족주의/원한/신뢰 |
| **사회경제** | 나이/교육/자산/고용 안정/이동성/계급(자본가/자영업/임금노동/실업/은퇴) |
| **정치** | 정치 관심/급진성/정당 충성/정당 일체감/회고 평가 |
| **정체성** | 지역/문화 집단/종파 |

심리 6축은 사건(위기·전쟁·부패·경기)에 반응하고, **항상성**으로 기준점에 되돌아간다. 이 항상성이 약하면 값이 한쪽 끝으로 포화된다 — 초기 버전에서 부족주의가 평균 0.98로 붙어버린 문제를 계수 교정으로 해결했다(왜도 −5.84 → −0.11).

좌우 위치(LR)는 심리 6축의 가중 합으로 계산된다. 정당 역시 같은 6차원 공간의 좌표를 갖는다.

### 2.2 투표 선택

매달 시민은 정당마다 효용을 계산한다.

```
효용 = −이념 거리 × 이념 가중(정치 관심이 높을수록 ↑)
       + 정당 일체감 + 밴드왜건 + 인지도(정치 자금)
       + 지역 친화 (지역주의 × 정당의 지역 기반)
       + 옷자락 효과 (동시선거 시 대통령 정당)
       + 쟁점 소유권/균열 정렬/회고 평가
```

**무당층은 "정당 간 차이가 없을 때"** 생긴다. 1·2위 효용 격차가 작으면 한쪽을 고르지 않는다. 예전에는 효용의 절대값으로 판정해 이념 가중을 올리면 전원이 무당층이 됐는데, 이를 무차별(indifference) 모델로 바꾸면서 **당파적 정렬이 0.08 → 0.34**로 올라갔다(현실 미국 0.60).

### 2.3 정당의 발생과 소멸

정당은 시민 공간에서 **빈 곳**이 생기면 창당된다. 이후 분당·합당·흡수·해산을 겪는다.

- **창당** — 기존 정당이 덮지 못하는 유권자 군집이 충분히 크면
- **분당** — 계파 갈등이 임계를 넘으면 소수 계파가 의원을 데리고 나간다
- **합당** — 선거연합이 굳어지면 하나로 합친다. **가장 큰 전신의 역사(창당 연도·연혁·이정표)를 잇는다**
- **흡수** — 노선이 가깝고 작은 당은 큰 당에 흡수된다. 흡수 기록이 남는다
- **소멸** — 지지율이 일정 기간 바닥이면 해산. **의원은 무소속으로 잔류**(의석 증발 없음)
- **후보 등록 마감** — 창당 6개월이 안 된 당은 그 선거에 후보를 못 낸다. 지지자의 65%는 노선이 가까운 당을 찍는다

당명은 문화권별 슬롯(이념어 + 접미)으로 생성되고, 이념 라벨은 **53종**으로 분류된다(아나키즘부터 준파시즘까지, 좌우 축 1차·심리 축 2차).

### 3.2 4층위 부품 설계

헌법 에디터의 **"선거제 상세 설계"**에서 9엔진을 넘어서는 조합을 만든다.

```
층위 1/의석 구성   방식(지역구/비례/혼합)/연동(병립/부분/연동)/지역구 비중
                    지역 최소의석/재외국민 선거구/기능별 선거구
층위 2/지역구      정수(균일/혼합)/당선 결정(단순다수/결선/선호/단기이양/집단명부/보르다)
                    결선 방식(상위 N / 문턱)/공천(1인/복수)/안분표
층위 3/비례        배분 범위(전국/권역/주)/명부(폐쇄/개방/자유/파노샤주)/누적투표
                    배분식(헤어/드룹/동트/생라게/수정생라게)/봉쇄조항/연합명부/독식
층위 4/보정        석패율/초과의석/다수당 보너스(정액/차등)/집단 유보의석
```

에디터는 **불가능한 조합을 이유와 함께 교정**한다.

- 선호투표 + 2인 이상 선거구 → 단기이양식으로
- 단기이양식·집단명부 + 1인 선거구 → 정수 3인으로
- 1인 선거구 + 복수 공천 → 1선거구 1인으로

그리고 **의석 예산**을 실시간으로 보여준다.

```
하원 300석 = 지역구 138 (46구 × 3인) + 비례 138 (전국) + 재외 12 + 기능별 12
```

모순(✕)과 주의(⚠)도 표시한다 — 권역당 비례 4석 미만, 봉쇄조항 7% 이상, 연동형인데 지역구 비중 70% 초과 등.

### 3.4 투표 행동

- **교차투표** — 지역구는 당선 가능한 큰 당, 정당투표는 노선이 선명한 작은 당. 혼합제(병립·연동·4층위 혼합)의 비례 몫에 반영. "지역구 0석 + 비례만" 경로(민주노동당 2004)가 생긴다. 받는 쪽 지지율에 비례하고 자기 표의 1.8배를 넘지 못한다
- **전략투표·사표 심리** — 소선거구에서 당선 가능성 낮은 정당 이탈
- **선거 전 조정** — 단일화·후보 양보·선거연합
- **출구조사** — 언론 자유도가 정확도를 정한다. 1위를 틀리면 언론 신뢰 하락

### 3.5 개표 상세 (지역구 모달)

지역구를 누르면 선거제별 **개표 과정**이 그대로 나온다.

- **결선투표** — 1차(진출/탈락) → 탈락 정당 표의 행방(80% 이동·20% 기권) → 결선 → 역전 여부
- **선호투표** — 라운드별 득표표(탈락자 취소선) + "3라운드: 자유당 탈락 → A +16.4%p/B +6.3%p/소진 2.5%p"
- **단기이양식** — 드룹 쿼터, 1순위 쿼터 배수(2.17Q), 단계별 당선·잉여 이양·탈락·소진
- **집단선거구** — 몇 %로 전 의석을 가져갔고 나머지 표가 얼마나 사표가 됐는지
- **중선거구** — 커트라인, 정당별 "균등 배분 시" 가능 의석 → **과소 공천 / 표 쏠림** 진단

공통 헤더에 정수·방식·지역구 유효정당수·사표율·정당별 의석 칩이 붙는다. 지역구는 "수도권 제3구"처럼 이름을 가진다.

## 4. 대통령·상원·선거인단

### 4.1 정부 형태

의원내각제/대통령제/이원집정부제/입헌군주제/절대군주제 등. 대통령제에서는 **대선 승리 즉시 정권이 넘어가고**, 의회 과반이 없으면 분점정부가 된다(미국형 프리셋에서 분점 약 40%).

대선은 결선투표·연임 제한·임기 어긋내기(중간평가 구도)를 지원한다. 후보 단일화와 당내 경선이 대선 전에 일어난다.

### 4.2 선거인단

헌법 에디터 → 대통령 → **선거인단**.

| 방식 | 사례 | 특성 |
|---|---|---|
| **주별 승자독식** | 미국 48개 주 | 득표 역전(2000·2016) 발생 |
| **주 내 비례** | 콜로라도 2004 발의안 | 역전은 사라지지만 과반 미달이 상시화 |
| **선출 선거인단** | 핀란드(~1988) | 선거인이 과반 나올 때까지 협상·재투표 |

- **선거인 총원**(60~1,200)/**주당 기본 몫**(0~10)/**선출형 규모**(100~3,000) 조정 가능
- **반란표(faithless elector)** — 신뢰가 낮을수록, 접전일수록 발생
- **하원 결선** — 과반 미달 시 상위 3명 중 하원이 **주별 1표**로 선출(미 수정헌법 12조). 선거인단 1위가 지면 "부패한 거래"(1824년)
- **권위주의 선출형** — 체제가 권위주의로 기울면 단독 후보 '체육관 선거'(통일주체국민회의형)

선거인단 팝업은 전용 레이아웃이다 — 당선선 표시 막대, 선거인 vs 전국 득표 **증폭 배율**, 격차순 주별 결과표, **분기점 주(tipping point)**, 경합주, 반란표 목록, 결선 라운드표.

|---|---|---|---|---|
| 승자독식 | 6 | 0 | 0 | — |
| 주 내 비례 | 0 | 30 | 10 | — |
| 선출 선거인단 | 0 | — | — | 22 |

### 4.3 상원

구성 방식: **연방형**(주당 균등/인구비례/승자독식)/**직선 비례**/**임명형**/**직능형**/**신분형**

**개선 방식** — 전면 / 절반(일본·프랑스) / **3분의 1(미국)**. 조(class)마다 의석을 따로 보유하고, 임기 ÷ 조 수마다 한 조만 교체한다. 연방형이면 주 r의 j번째 의석이 (r+j) mod K 조에 속해, 주당 2석·3조면 어떤 해에는 선거가 없는 주가 생긴다(미국과 동일).

## 5. 헌법과 개헌

### 5.1 헌법 에디터

하원(선거제·정수·임기·투표 연령·공천·중간선거·의무투표), 상원, 대통령(임기·연임·결선·선거인단·예비선거 법제), 연방 구조, 개헌 경직도를 편집한다.

- **연성헌법** — 적용 즉시 반영
- **경성헌법** — 의회 표결 → (필요시) 국민투표 절차를 거친다

### 5.2 자연 발생 개헌

정당들이 자기 이익에 따라 개헌을 발의한다. 의제 **27종**:

```
선거제    비례 강화/다수제 회귀/특수 제도/봉쇄조항/결선/선거구/복수 공천
정수      의원정수 확대 ↔ 축소/투표 연령 하향 ↔ 상향
임기      임기 연장 ↔ 단축/연임 제한 ↔ 해제/중간선거
정부형태  대통령제 ↔ 의원내각제 ↔ 이원집정부제
공천      개방(경선) ↔ 중앙화
상원      도입/폐지/개편(5종)
연방      분권 ↔ 집권
개헌요건  강화 ↔ 완화       ← 헌법이 헌법을 바꾼다
군부      민간 통제/군부 특권
```

과소대표 정당은 정수 확대를, 야당은 중간선거를, 여당은 개헌 요건 강화를 원한다.

## 6. 정당과 정치인

- **계파** — 정당 안에 2~5개 계파가 지분·급진성·대표를 갖고 경쟁. 분당의 씨앗
- **경선** — 계파가 후보를 낸다. 공천 방식(지도부 지명/당원 경선/개방형)이 결과를 바꾼다(May의 법칙). 결선·역전·패배 계파 반발
- **정치인 생애** — 입문·선수·계파 수장·당대표·장관·국가 지도자 경력. 카리스마·청렴·야심
- **의원 개체** — 300명 의원이 각자 성향과 경력을 가진다. 현역 프리미엄, 교차 투표
- **정당 조직력** — 당원 기반. 지지자 이탈을 붙잡는다
- **정당 간 갈등** — 쌍별 갈등이 누적되면 연정 불가 선언
- **선거연합·전선·방역선(cordon sanitaire)** — 극단 정당 배제 협약
- **스캔들의 생애** — 폭로 → 부인 → 증거 → [꼬리 자르기 / 사과 / 버티기] → 결말
- **정치 자금** — 국고보조금·당비·후원금·기업 후원. 자금법(공영/혼합/자유)에 따라 구성이 달라진다. 지출 → 인지도 → 득표
- **이정표** — 첫 원내 진입/첫 집권/제1당 등극/단독 과반/개헌선 돌파/창당 50/100/200년/몰락/원내 복귀/흡수 합당

## 7. 사회·경제·언론

### 7.1 경제

GDP 성장·실업·물가·재정(세율·복지·부채)이 정부 이념에 따라 움직인다. 좌파는 고세율·고복지, 우파는 감세·저복지를 목표로 한다. 재정 위기·경제 위기·자원 지대(지대국가화)가 있다.

**자산 분포**는 지니 0.43~0.47(현실 0.28~0.52 범위)로 교정되어 있다.

### 7.2 지역주의

프리셋 고정값이 아니라 **경제와 상황이 정하는 변수**다.

```
낮추는 것  도시화/이동성/전쟁(국민 통합)
높이는 것  지역 간 경제 격차/지역 불만/자치 격차/지역정당 조직화(자기강화)
```

근대화론(하락)과 주변부 저항론(상승)이 한 궤적에서 충돌해 **U자**가 나온다. 지역 간 격차는 표준편차로 재서 지역 수가 늘어도 부풀지 않는다.

### 7.3 언론

- **언론 자유** — 권위주의에서 하락
- **언론 편향** — 매체 5개가 정파성·점유율·의제(경제 성과/의혹 검증)를 가진다. 시민은 자기 성향 매체를 고르고(선택적 노출), 그 의제가 회고 평가를 민다. 정보 환경 분화가 양극화를 키운다
- **직접행동** — 시위·파업

### 7.4 사법

재판관 9명이 개체로 존재한다. 임기 만료 시 현 정권이 지명하고, 여소야대면 편향이 완화된다. 여당 지명이 2/3를 넘으면 "사법부 장악 논란". 위헌심사가 실제 법정 구성을 반영한다.

### 7.5 사회과학 지표

| 지표 | 내용 |
|---|---|
| 자산 지니/팔마 비율/상위 10%/1%/하위 40% | 불평등 |
| 당파적 정렬 | 정당과 이념의 결합 강도 |
| 투표율 격차 | 학력·연령·자산별 |

## 12. 실험 도구

### 헌법 고정 (`constLock`)

개헌 발의와 **국민투표 공포 경로를 모두** 차단한다. 특정 제도의 장기 효과를 측정할 때 필수다.

> **방법론 교훈** — 제도를 측정할 때는 반드시 헌법을 고정하고, 구동 후 `con.method`가 유지된 시드만 집계해야 한다. POLIS는 개헌이 자연 발생하므로 100년 뒤 시작 제도가 유지된다는 보장이 없다. 이를 놓쳐 엔진에 없는 결함을 두 차례 보고한 적이 있다.

### 실험 모드 (Lab Mode)

개헌 절차는 그대로 두고 **빈도와 다양성만** 높인다(주기 7년→1년, 발동 30%→95%, 통과 요건 2/3→42%, 의제 가중 무작위). 400년에 고유 제도 조합이 12 → 27개로 늘어난다.

### 기타 고정 스위치

`ideologyLock`(이념 고정)/`dynastyLock`(왕조 고정)/`regionalismLock`(지역주의 고정)/`partyLock`(정당 체계 고정)

### 저장·불러오기

전체 상태를 JSON으로 직렬화한다. 정당·계파·의원·헌법·선거 기록·문서·경선·스캔들·재판관·언론 매체·상원 조별 의석·주별 당파 성향까지 보존된다.


## 이론적 배경

POLIS가 재현하려는 주요 이론들:

- **뒤베르제 법칙** — 소선거구는 양당제로, 비례제는 다당제로
- **립셋-로칸 균열 이론** — 계급·지역·종교·도농 균열이 정당 체계를 만든다
- **잉글하트 탈물질주의** — 세대 교체가 가치 균열을 바꾼다
- **May의 법칙** — 당원은 지도부보다 급진적이다
- **다운스 중위투표자/공간 경쟁**
- **레비츠키-지블랫** — 민주주의는 개헌이 아니라 규범 붕괴로 무너진다
- **슈가트-캐리** — 선거 시기 배치가 정당 체계를 바꾼다
- **근대화론 vs 주변부 저항론** — 지역주의의 부상과 쇠퇴
- **반사실 선거/갤러거 지수/유효 정당 수(락소-타게페라)**
